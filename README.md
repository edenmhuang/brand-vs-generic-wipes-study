# Math 200: Elementary Statistics & Probability

A collection of datasets used for my Elementary Statistics and 
Probability course at Skyline College. The course covered 
statistical concepts using Python and Pandas alongside 
traditional hand-written assignments.

## Datasets

| File | Description |
|------|-------------|
| breakfast_survey.csv | Survey data on breakfast habits |
| honda_accord_values.csv | Honda Accord LX FWD depreciation over time |
| diamonds.csv | Diamond pricing and characteristics |
| san_diego_home_values.csv | San Diego housing market values |
| laptops.csv | Laptop pricing and specifications |
| qqq_etf.csv | QQQ ETF historical price data |
| repair.csv | Repair cost data |
| weekly_expenses.csv | Weekly personal expense tracking |
| wipes_survey.csv | Survey data on wipes usage |
| wipes_survey_2.csv | Follow-up survey data on wipes usage |
